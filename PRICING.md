## Optional services

| Service | Description | Pricing |
| --- | --- | --- |
| Community support | Public issue tracker, best-effort response | Free |
| Support & SLA (basic) | Defined response windows for questions and incidents | on request |
| Support & SLA (plus) | Tighter windows, named contact, escalation path | on request |
| Integration assistance | Bespoke wiring into a customer case-management workflow via the documented CLI + JSON interface | per engagement |
| Training | Operator + forensic-reviewer training (DE / EN), on-site or remote | per engagement |
| Assurance & review support | Help preparing evidence for an external audit, penetration test or accreditation | per engagement |

> Prices are not published as fixed tiers because service scope varies by operator
> size and integration depth. Ask the maintainers for a quote — see `SUPPORT.md`
> for the contact route. No support obligation exists unless a service is ordered.

## Response targets

Response targets apply **only** to an ordered support service, and only to the
service engagement — not to the MIT-licensed code:

| Service level | Response target | Channel |
| --- | --- | --- |
| Community | best-effort | public issue tracker |
| Basic | 3 business days | email / tracker |
| Plus | 1 business day | email / tracker |

Severity definitions: Sev-1 = production outage or data-unavailability;
Sev-2 = degraded function with a workaround; Sev-3 = minor or cosmetic.

## What is not for sale

- **The MIT License itself** — it is granted in full, for free, forever.
- **A right to use the code** — there is no such gate to sell.
- **External audit or attestation** — an independent third party always performs
  these; the project can only help you prepare.
- **Legal advice or eIDAS qualified electronic signature (QES)** — FieldSeal Suite
  explicitly provides neither (see `docs/disclaimer.md`).
- **Hardware, field devices or cloud infrastructure** — you run the software on
  your own.
- **German-language localization of compliance templates beyond what ships** —
  available as a paid service.
