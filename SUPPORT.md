# Support — FieldSeal Suite

FieldSeal Suite is MIT-licensed and **free to use**. Paid support is an **optional
service** — it is not a licence, not a requirement, and not a condition of using the
software. See `COMMERCIAL-LICENSE.md` and `PRICING.md`.

## Channels

| Need | Channel |
|---|---|
| General questions | the repository issue tracker |
| Security vulnerability | private repository security advisory (see `SECURITY.md`); never a public issue |
| Optional paid support | the contact stated in the executed Order Form; absent an Order Form, the repository issue tracker |
| Data-protection request | the operator/controller's DPO or legal team; the publisher holds no customer evidence |

No support email is published here because an unmonitored address is worse than none.
Security reports use the private advisory; paid engagements use the Order Form contact.

## Community support (free)

Public issue tracker, best-effort response. No response-time commitment. Community support
carries **no** service obligation and no SLA.

## Optional paid support

Response targets apply only to an ordered support service, never to the MIT-licensed code:

| Service level | Target | Scope |
|---|---|---|
| Basic | 3 business days | email/ticket support, minor guidance |
| Plus | 1 business day | priority handling, named contact, escalation path |

Severity: Sev-1 = production outage or evidence unavailable; Sev-2 = degraded function with a
workaround; Sev-3 = minor/cosmetic.

## Before you ask

Run the precheck in `Manual-Test-Checklist.md` §1 and attach the exact command/output. Do not
attach customer evidence, passphrases or private keys. For a suspected integrity failure,
preserve the first artefact and its hash; do not re-seal it.
