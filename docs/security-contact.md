# Security contact / Sicherheitskontakt

**Authoritative channel:** the repository's private security advisory ("Report a vulnerability"
under Security → Advisories). This keeps the report private and gives the maintainers a
traceable thread.

- **Do not** open a public issue for a suspected vulnerability.
- **No PGP key is published.** Do not send exploit details or secrets by plain email. If
  encrypted email is required, request a key inside the private advisory first.
- **Response target:** acknowledgement within 2 business days; triage within 5 business days.
- **Scope:** v0.5 (released) and v0.4 (stable); older versions are accepted for verification
  compatibility but are not supported for fixes.

An earlier revision mentioned a PGP key placeholder. No such file is published, and no PGP key will be listed here until it is generated, published and actually monitored.
