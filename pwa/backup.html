Backup & Restore

Everything stays on this device. Exports never leave the browser unless you choose to copy the file.

1. Export a full local backup

Includes all four IndexedDB object stores (cases, evidence packages, ciphers, signature images), the local operation trail and UI preferences, as JSON.

2. Verify & restore

Restore replaces all local cases with the contents of a previously exported JSON. It cannot be undone, so export first.

No file selected

3. Offline CLI verification

Package the exported JSON into a checksum-protected ZIP, verify it offline, and unpack it again:

node cli/bin/backup.mjs export --input fieldseal-backup.json --out fieldseal-backup.zip
node cli/bin/backup.mjs verify --input fieldseal-backup.zip
node cli/bin/backup.mjs restore --input fieldseal-backup.zip --out restored.json

A verified JSON can be imported again with the Restore button above. See Privacy & legal.
